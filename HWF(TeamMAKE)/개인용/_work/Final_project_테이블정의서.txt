1. 공통 규칙
1. 값 이름: 상태 칸의 값은 API 명세서의 값과 글자까지 같게 쓰고, 정해진 값만 들어가도록 CHECK 제약을 건다. 값을 더하거나
바꿀 때는 두 문서를 함께 고친다.
2. id: 대부분 uuid( gen_random_uuid() )를 쓴다. 기록이 계속 쌓이는 로그 테이블만 bigserial(1씩 커지는 숫자)을 쓴다.
3. 시각: 모두 timestamptz 로 저장하고, 화면과 정해진 시각 작업은 한국 시간(Asia/Seoul)으로 계산한다.
4. 점수: 계산한 점수는 numeric(5,2) 로 저장해 소수 오차가 없게 한다(예: 70.15). API에는 문자열로 내보낸다.
5. 암호화 칸: 이름이 _enc 로 끝나는 칸은 서버 코드에서 AES-256-GCM으로 암호화한 값( bytea )이다.
6. 지울 때: 지원 건을 지우면 그 아래 행(질문·답변·점수·결과·기록·녹화)도 함께 지운다( ON DELETE CASCADE ). 동의
(consents)는 증거로 남기고 연결만 끊는다( ON DELETE SET NULL ). 지운 일은 deletion_logs에 남긴다.
7. 탈퇴: users 행을 바로 지운다. 그래서 같은 이메일로 다시 가입할 수 있다.
8. LangGraph 체크포인트: checkpoints · checkpoint_blobs · checkpoint_writes 테이블은 LangGraph가 직접 만들고
관리한다. thread_id는 지원 건 id이고, 지원 건을 지울 때 함께 지운다.
