## (C) 확인 못 한 것

1. `.env`(지침에 따라 읽지 않음): `APP_PROFILE`, `APP_ENCRYPTION_KEY`, `CAPTION_INTERVAL_SEC`, `LLM_RT_PARALLEL` 의 실제 값. B2 가 실제로 일어났는지, A9 의 운영 자막 간격이 1초인지는 모름.
2. 실행·테스트: 이 검토에서 `pytest`·E2E·compose 기동을 하지 않았다. B3·B5·B7·B8 의 영향은 코드 읽기에서 나온 추정이다.
3. LangGraph 동작: 새 연결마다 `ainvoke({"seq": 0}, config)` 를 같은 `thread_id` 에 다시 호출하는 것이 이전 `interrupt` 상태를 안전하게 폐기하는지(`engine.py:516`)는 라이브러리 동작을 직접 실행해 보지 않았다. 로컬 Python 3.10 에서는 그래프 테스트 4개가 건너뛰어졌고(M-1), 이어가기는 E2E 로만 간접 확인됨.
4. 읽지 않은 코드: `admin_ops.py`(통계 계산식·`ops-status`), `question_bank.py`, `rag.py`, `posting_draft.py`(T9 재생성·금지어), `coding_bank.py`, `resume_extract.py` 앞부분(리더·OCR 판정 기준 50자/5%), `migrate.py`, `devtools.py`, `ai/ocr/server.py`·`ai/embed/server.py`·`ai/tts/server.py` 본문. 해당 문서 부분(TRD 7-6 ②, 7-4 ①, 통계 항목, 예비 질문 수)은 대조하지 못했다.
5. TTS: CPU 는 `compose.ai.yml` 과 `ai/tts/server.py` 첫 줄(docstring)로만 확인했고 ONNX 실행 공급자(provider)가 실제 CPU 인지는 보지 않았다.
6. OCR 기울기 보정·300dpi 여부(TRD 논의 #23): `ai/ocr/server.py` 를 열지 않아 판단하지 않았다. 코드의 렌더 해상도는 200dpi(`resume_extract.py:36`).
7. 화면 쪽: `offline`·`blur`·업로드 재시도는 `frontend/app/exam/…/page.tsx`·`frontend/lib/recording.ts` 의 일부만 grep 했다. 화면이 B4 의 진행 중 상태를 자체 시간 제한으로 끊는지는 모름.
8. 화면정의서·플로우차트·시나리오·PRD 앞부분(1~5-4장)은 이 역할의 범위 밖이라 검토하지 않았다.
