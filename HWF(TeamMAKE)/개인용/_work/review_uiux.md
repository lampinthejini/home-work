# UI/UX 검토 결과 (개인용 개정본, 2026-11-03)

검토 대상: 화면정의서 v0.7(주), 시나리오 기획서 v1.1 덤프, PRD v1.7(4장·8장·5-10·5-11·7-2·7-3), 플로우차트 09v(지원자 흐름).

심각도: 높음 = 지원자가 잘못 알고 응시하거나 동의가 불완전해질 수 있음 / 중간 = 혼란·재문의 가능 / 낮음 = 다듬기.

## (C) 확인 못 한 것

1. 화면정의서 §10~13(관리자 화면, 기술 문제, 추적표)은 지원자 흐름 중심이라 읽지 않았다. 알림 숨기기와 비교 경고만 grep으로 확인했다.
2. 시나리오 기획서 원본(docx)이 아니라 덤프 txt만 봤다. 표 구조가 덤프에서 풀렸을 수 있다. 플로우차트는 mermaid 전체가 아니라 지원자 흐름 부분을 grep으로 봤다.

5. `Precheck.tsx`, `Shell.tsx`(GNB·모바일 안내), 공고 목록·상세, 비밀번호 화면, 코딩테스트 화면(`Coding.tsx`)의 문구·접근성은 부분적으로만 봤다.
