# 이용자 가이드 — 지원자용

AI 1차 면접 플랫폼에서 공고를 찾아 지원하고, AI 면접(과 코딩테스트)을 보고, 결과를 확인하는 방법입니다.
(2026-11-10 기준 프로그램 동작에 맞춰 썼습니다.)

---

## 1. 시작하기 전에 준비할 것

| 준비물 | 이유 |
|---|---|
| **PC** (Windows·Mac) | 지원·면접은 PC 전용입니다. 모바일에서는 공고와 결과만 보세요(화면 위에 안내가 나옵니다). |
| **Chrome 또는 Edge 120 이상** | 녹화·음성 기능이 이 브라우저에서만 안정적으로 동작합니다. |
| **카메라·마이크·스피커(이어폰)** | 질문은 음성으로 나오고, 답변은 말로 합니다. 카메라 녹화도 함께 합니다. |
| **안정적인 인터넷** | 1Mbps 미만이면 환경 점검을 통과하지 못합니다. 5Mbps 이상을 권장합니다. |
| **조용한 곳, 약 30분~1시간 반** | AI 면접 약 25분, 코딩테스트가 있으면 60분이 더 걸립니다. |
| **메신저 등 알림 끄기** | 다른 창이 뜨면 '화면 이탈'로 셀 수 있습니다. |

---

## 2. 전체 흐름 한눈에 보기

```
회원가입 → 공고 보기 → [지원하기] → ① 동의 → ② 이력서 → ③ 환경 점검 → ④ 시작 안내
→ AI 면접(질문 10개 + 꼬리질문) → (코딩테스트가 있는 공고만) 코딩테스트 → 응시 완료
→ 결과 공개일에 알림·메일 → 마이페이지에서 결과 보기
```

---

## 3. 회원가입과 로그인

1. 오른쪽 위 **[회원가입]** → 이름·이메일·휴대전화·비밀번호를 넣고 약관에 동의합니다.
2. **[로그인]** 으로 들어갑니다.
3. 비밀번호를 잊었다면 로그인 화면의 **비밀번호 찾기**에서 이메일로 재설정 링크를 받습니다. 링크는 한 번만 쓸 수 있습니다.

> 같은 곳에서 비밀번호를 5번 틀리면 잠시 로그인이 막힙니다. 시간이 지나면 다시 시도할 수 있습니다.
> 오래 쓰지 않아 로그인이 끝나면 "로그인이 끝났습니다. 다시 로그인해 주세요" 알림과 함께 로그인 화면으로 이동합니다.

---

## 4. 공고 보고 지원하기

1. **채용 공고** 메뉴에서 공고를 고릅니다. 접수 기간, 결과 공개일, 코딩테스트 포함 여부가 나옵니다.
2. **[지원하기]** 를 누릅니다. 공고 하나에 **한 번만** 지원할 수 있습니다.

### ① 동의

다섯 가지에 모두 동의해야 다음으로 갈 수 있습니다. **[자세히 ▾]** 를 눌러 내용을 꼭 읽어 주세요.

| 항목 | 핵심 내용 |
|---|---|
| ① 응시 데이터 수집·이용 | 이력서, 답변 음성·글, 카메라 녹화, 코드, 장애·이탈 기록 |
| ② AI 자동 채점과 1차 결정 | AI가 항목별로 채점하고, 시스템이 계산한 총점이 합격 기준 이상이면 1차 합격 |
| ③ 관리자에게 결과 제공 | 공고 관리자가 결과·답변·이력서·기록을 봅니다 |
| ④ 보관 기간 | 응시 데이터는 결과 공개일부터 7일, 녹화는 3일 뒤 자동 삭제 |
| ⑤ 응시 규칙 | 1회만 응시 · 중단 버튼 없음 · 화면 이탈 1회 경고, 2회 응시 취소(1차 불합격) · 연결이 끊기면 이어가기 3회까지 |

### ② 이력서

세 가지 방법 중 하나를 고릅니다.

- **파일 올리기 (PDF·JPG·PNG):** AI가 글을 읽어 학력·경력·기술 칸을 채워 줍니다.
  - PDF는 **앞 10쪽까지만** 읽습니다.
  - 스캔본·사진은 글자 인식(OCR)을 써서 시간이 더 걸립니다. 화면에 예상 시간이 나옵니다.
  - 파일이 너무 크면 "파일이 너무 커서 받을 수 없습니다. 용량을 줄여 다시 올려 주세요." 가 나옵니다.
  - 사진 화질이 낮으면 띄어쓰기가 사라져 학교·전공이 한 칸에 붙을 수 있습니다. **확인 화면에서 꼭 고쳐 주세요.**
- **마이페이지에 저장한 이력서 불러오기**
- **직접 작성:** 성명과 학력(또는 경력)은 꼭 넣어야 합니다.

마지막으로 **[제출하기]** 를 누르면 이력서가 확정되고 더는 고칠 수 없습니다.
이때부터 AI가 이력서와 공고를 바탕으로 **면접 질문 10개를 미리 준비**합니다.

### ③ 환경 점검

다섯 가지가 모두 통과해야 합니다.

| 점검 | 통과하는 법 |
|---|---|
| ① 마이크 | 말하면 막대가 움직이는지 봅니다. 마이크가 여러 개면 목록에서 고릅니다. |
| ② 카메라 | 화면에 내 얼굴이 보이는지 봅니다. |
| ③ 스피커 | **[테스트음 재생]** 후 **[들려요]** 를 누릅니다. 여기서 고른 스피커로 면접 질문 소리가 나옵니다. |
| ④ 네트워크 | 자동으로 잽니다. |
| ⑤ AI 서버 | 자동으로 확인합니다. 실패하면 잠시 뒤 **[다시 점검]** 을 누릅니다. |

통과 표시는 **15분 동안** 유효합니다. 너무 오래 기다리면 다시 점검합니다.

### ④ 시작 안내

응시 규칙을 다시 확인하고 체크한 뒤 **[면접 시작]** 을 누릅니다. 화면이 전체 화면으로 바뀝니다.

> 동시에 면접을 볼 수 있는 사람 수가 정해져 있습니다. 자리가 없으면 안내 창이 뜨고, 자리가 나면 **[다시 시도]** 로 시작합니다.

## 5. AI 면접 보는 법

- **질문:** 기본 질문 10개(인성 2 · 이력서 기반 2 · 기업 관련 2 · 직무 4), 꼬리질문은 최대 4개입니다.
- **진행 순서:** AI가 질문을 **음성과 자막**으로 읽음 → **3-2-1** 카운트다운 → 답변 녹음 시작
- **답변 시간:** 기본 질문 90초, 꼬리질문 60초. 다 말했으면 **[답변 완료]** 를 눌러도 됩니다.
- **자막:** 말하는 동안 내가 한 말이 글자로 나옵니다(채점은 답변이 끝난 뒤의 최종 글자로 합니다).
- **꼬리질문:** 답변이 모호하거나 근거가 부족하면 AI가 한 번 더 물어볼 수 있습니다. 꼬리질문이 나왔다고 감점은 아닙니다.
  - "~한 적이 있나요?"처럼 예/아니오로 답할 수 있는 질문에 "네"처럼 짧게만 답하면 "그렇게 답하신 이유를 구체적으로 말씀해 주세요."라고 다시 묻습니다. 처음부터 이유와 상황을 함께 말하면 좋습니다.

### 하면 안 되는 것

| 행동 | 결과 |
|---|---|
| 다른 탭·창으로 이동, 전체 화면 해제(ESC 포함) | **1회:** 경고 후 멈춘 시점의 남은 시간부터 이어서 (코딩테스트는 시간이 멈추지 않아요. 벗어나 있던 시간도 코딩 시간에서 빠져요) · **2회:** 면접 자동 취소(1차 불합격) |
| 새로고침, 창 닫기 | **응시 종료.** 다시 응시할 수 없고, 답변한 문항까지만 평가합니다. |
| 마이크·카메라 권한을 직접 끄기 | **응시 종료** |

### 연결이 끊겼을 때 (장애 중단)

인터넷·장치 문제로 끊기면 **답변은 안전하게 저장**되고 '장애 중단' 화면이 뜹니다.

1. 화면에 **남은 이어가기 횟수**가 나옵니다. (예: "이번에 이어간 뒤에도 연결 끊김이 2번 더 생기면 다시 이어갈 수 있습니다")
2. 연결이 돌아오면 **[마이페이지에서 이어가기]** → 재점검 → **[이어서 시작]**
3. 끊긴 질문은 **처음부터 새 답변 시간**으로 다시 합니다. 감점은 없습니다.
4. 이어가기는 **3번까지**입니다(서버 문제로 끊긴 것은 세지 않습니다). 그다음 또 끊기면 응시가 끝나고 답변한 문항까지 평가합니다.
5. **접수 마감 시각**까지만 이어갈 수 있습니다.

> 면접을 시작했는데 화면이 서버에 한 번도 연결되지 않으면 "면접 서버와 연결되지 않았습니다" 화면이 뜹니다. 2~3분 기다리면 장애 중단으로 바뀌어 이어가기를 할 수 있습니다.

### 접수 마감이 되면

진행 중이어도 마감 시각에 면접이 끝납니다. 그때 답하던 문항과 남은 문항은 0점입니다.

## 6. 코딩테스트 (해당 공고만)

- AI 면접이 끝나면 안내 화면이 나오고, **60초 뒤 자동으로 시작**합니다(바로 시작도 가능).
- **Python 3 · 2문항 · 60분.**
- **[실행]** 으로 예시 입력을 돌려 볼 수 있습니다. 코드는 인터넷이 막힌 안전한 상자에서 실행됩니다.
- 코드는 **30초마다, 그리고 문제 탭을 바꿀 때 자동 저장**됩니다. 끝나기 5초 전에도 한 번 더 저장합니다. 저장에 계속 실패하면 알림이 뜹니다.
- 시간이 끝나면 마지막 저장 코드가 **자동 제출**됩니다.
- 화면 이탈 횟수는 면접과 합쳐 셉니다(1회 경고, 2회 응시 취소). 다만 **코딩테스트는 경고가 떠도 시간이 멈추지 않습니다.** 화면을 벗어나 있던 시간도 60분에서 빠집니다. 붙여넣기는 막혀 있습니다.

## 7. 결과 확인

1. 결과는 **공고에 적힌 결과 공개일(마감 다음 날 10:00)** 에 열립니다. 🔔 알림과 메일로 알려 드립니다.
2. **마이페이지 → 결과** 에서 **[결과 보기]** 를 누릅니다.
   - 1차 합격·불합격, 종합 점수, 항목별 점수, 강점과 개선점, AI가 쓴 결과 이유
3. 결과는 공개일부터 **7일 동안** 볼 수 있고, 그 뒤 자동으로 지워집니다.

> 채점이 늦어지면 "결과 산출이 늦어지고 있습니다. 산출이 끝나는 대로 안내드립니다" 가 나옵니다. 끝나면 다음 날 공개됩니다.
> 시스템 문제로 자동 채점을 끝내지 못하면 담당자가 직접 결정할 수 있습니다. 그 경우 결과 화면에 '담당자 결정'이라고 나옵니다.

## 8. 마이페이지

| 탭 | 할 수 있는 것 |
|---|---|
| 지원 내역 | 진행 상태 보기, 다음 단계 이어 하기, 장애 중단 건 **[면접 이어가기]** |
| 결과 | 공개된 결과 보기, 공개 예정일 확인 |
| 이력서 | 다음 지원에 쓸 이력서 저장·수정·삭제 |
| 동의 관리 | 동의 철회 — 진행 중인 응시가 취소되고 데이터가 바로 지워집니다 |
| 회원 정보 | 이름·휴대전화 수정, 비밀번호 변경, **회원 탈퇴**(비밀번호와 '탈퇴' 입력 필요, 지원 데이터도 함께 삭제) |

## 9. 자주 묻는 질문

**Q. 면접 중에 잠깐 멈출 수 있나요?**
A. 없습니다. 중단·일시정지 버튼이 없습니다.

**Q. 답변을 다시 할 수 있나요?**
A. 한 번 넘어간 질문은 다시 할 수 없습니다. 장애로 끊긴 질문만 처음부터 다시 합니다.

**Q. 표정·시선으로 점수를 매기나요?**
A. 아니요. 채점은 **답변 내용(글)** 으로만 하고, 녹화는 평가에 쓰지 않습니다.

**Q. AI가 내 답변에 없는 말을 근거로 채점하면요?**
A. 시스템이 AI가 고른 근거 문장이 **실제 답변 안에 있는지** 확인하고, 없으면 그 근거를 쓰지 않습니다.

**Q. 이어가기 횟수를 다 썼는데 또 끊겼어요.**
A. 응시가 끝나고, 답변한 문항까지 평가합니다.
