# E2E 테스트 (Playwright)

실제로 떠 있는 Docker 스택(`sh scripts/up.sh`)에 브라우저로 붙어 사용자 흐름을 끝까지 확인합니다.
AI(LLM·STT·TTS·임베딩)도 진짜로 돌기 때문에 한 번에 약 4~5분 걸립니다. 앱 코드는 바꾸지 않습니다.

## 실행

```sh
cd e2e
npm install
npx playwright install chromium   # 처음 한 번
npm test                          # 전체 (약 4~5분)
npm run test:headed               # 브라우저 창을 띄워 눈으로 보기
npm run report                    # 실패했을 때 화면·영상·trace 보기
```

브라우저 확인용으로 데이터를 남기려면 `E2E_KEEP=1 npm test` — 마지막 탈퇴 단계와 정리를 건너뜁니다.
남은 `[E2E]` 공고는 관리자 화면에서 마감하면 되고, 다음 `npm test` 때 남은 E2E 지원자는 자동으로 지워집니다.

## 무엇을 확인하나

| 파일 | 흐름 |
|---|---|
| `tests/auth.spec.ts` | 회원가입(동의·전화번호 형식) → 틀린 비밀번호 거부 → 로그인 → 비밀번호 찾기 → **Mailpit 메일 1통**(1분 제한) → 링크로 변경 → 같은 링크 재사용 거부 → 옛 비밀번호 거부·새 비밀번호 로그인 → 회원 탈퇴 |
| `tests/interview.spec.ts` | 지원 → 동의 5개 → 이력서 직접 작성 → 환경 점검 5개(가짜 카메라·마이크) → 전체 화면 시작 → 첫 질문·답변 녹음 → **녹화 10초 조각 업로드** → **화면 이탈 1회 경고 · 2회 응시 취소** → 관리자: **녹화 재생**(200, video/webm, 재생 오류 없음)·**메모 쓰기/고치기/지우기** → 지원자 탈퇴 후 지원 데이터 404 |
| `tests/outage.spec.ts` | 면접 중 **연결 끊김** → '연결이 끊겼습니다' 안내(오프라인이면 이어가기 버튼 꺼짐) → 서버가 **장애 중단(interrupted)** 으로 기록 → 다시 연결되면 마이페이지 → 면접 이어가기 → 재점검 → **1번 질문부터 다시** |
| `tests/flow.ts` | 공용 흐름(로그인 → 지원 → 동의 → 이력서 → 환경 점검 → 면접 시작 → 첫 질문). 테스트 파일이 아님 |

## 구성

- `global-setup.ts` — 테스트 전용 관리자 `e2e-admin@test.local` 의 비밀번호를 실행할 때마다 무작위로 정하고(api 컨테이너 안에서 앱의 해시 함수로 저장, 실제 관리자 비밀번호는 쓰지 않음), **코딩테스트가 꺼진** `[E2E]` 공고를 API 로 게시합니다.
- `global-teardown.ts` — 남은 E2E 지원자(`e2e-auth-*`, `e2e-exam-*@test.local`)를 앱의 탈퇴 처리로 지우고, 공고를 마감·삭제하고, 관리자 비밀번호를 다시 아무도 모르는 값으로 바꿉니다.
- `fixtures/answer.wav` — 가짜 마이크 소리. TTS 컨테이너(Supertonic)로 만든 한국어 답변 앞에 2초 스윕음을 붙였습니다.
  환경 점검의 "마이크 소리 1초 이상 연속" 조건이 말소리 사이 쉼 때문에 통과하지 않아서입니다(잡음 억제가 일정한 배경음은 지움).
- 연결 끊김은 `page.routeWebSocket` 으로 면접 WebSocket 을 중간에서 이어 주다가 양쪽을 닫아 만듭니다. `setOffline` 만으로는 Chromium 이 이미 열린 WebSocket 을 끊지 않기 때문입니다.
- 실행 상태(`.state.json`)·결과(`test-results/`, `playwright-report/`)는 git 에 올리지 않습니다.

## 환경변수

| 이름 | 기본값 |
|---|---|
| `E2E_BASE_URL` | `http://127.0.0.1:8080` (WebSocket 출처 검사 때문에 `localhost` 가 아니라 이 주소여야 함) |
| `E2E_MAILPIT_URL` | `http://127.0.0.1:8025` |
| `E2E_API_CONTAINER` | `huge-app-api-1` |
| `E2E_KEEP` | 비움. `1` 이면 지원자·공고를 남김 |

## 아직 없는 것

- 면접 10문항을 끝까지 마친 뒤 채점·결과 공개 (채점에 70~181초, 결과는 공개 시각에 열림)
- 코딩테스트가 켜진 공고의 코딩 단계
