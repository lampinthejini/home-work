# AI 채용 플랫폼 Mermaid 플로우차트 통합본 v0.4

> 수정: 2026-10-22. 공개 공고 페이지에서 일반 로그인하면 공고 페이지로 복귀하고, 특정 공고 지원 도중 로그인하면 해당 지원 절차로 복귀하도록 반영했다. 관리자 계정은 관리자 대시보드로 이동한다. `returnTo`는 허용된 내부 경로로만 검증하고 지원하려던 `jobId`를 보존한다.

> **표기 주의:** 회의에서 미확정된 질문 수(관리 슬롯 10개 vs 면접 구성 12개), 꼬리질문 상한, UI 배치 등은 최종 확정값으로 간주하지 않는다.

## 01B_로그인_복귀경로

```mermaid
flowchart TD

 D --> E{"인증 상태"}
 E -->|"로그인 안 됨"| F["로그인 / 회원가입 모달"]
 E -->|"지원자 로그인됨"| J["해당 공고 지원 절차"]
 E -->|"관리자 로그인됨"| Z["지원자 권한 필요 안내"]
 B --> F
 F --> G{"인증 성공?"}
 G -->|"아니오"| F
 G -->|"예"| H{"사용자 역할"}
 H -->|"관리자"| I["관리자 대시보드"]
 H -->|"지원자"| K{"로그인 요청 출처"}
 K -->|"상단 로그인"| A

 J --> L["개인정보 동의 / 서류 등록"]

```

 B -->|예| C[관리자 입력 질문]
 B -->|아니오| D[SQL: 분야 / 난이도 / 활성 질문 필터]
 D --> E{적합 질문 충분?}
 E -->|예| F[질문은행 선택 + 중복 제거]
 E -->|아니오| G[기업 공개문서 / 직무자료 Retriever]

 F --> K

 M --> N{품질 오류?}
 N -->|예| O[전사 확인 / 재녹음]
